# P-N Junction VR Lab — Controls Reference

All gameplay interactions use **XR Interaction Toolkit (`3.7.0`)**, **OpenXR (`1.19.0`)**, and the **Unity Input System (`1.20.1`)**. No legacy Input Manager or hard-coded gameplay key listeners are used.

The **XR Interaction Simulator** (`XRDeviceSimulatorSettings.asset`) is **enabled in Editor Play Mode only** (`m_AutomaticallyInstantiateSimulatorPrefab = 1`, `m_AutomaticallyInstantiateInEditorOnly = 1`), so desktop mouse/keyboard testing works in Unity Editor without affecting Meta Quest 3 APK builds.

---

## 0. Meta Quest 3 Touch Plus Controller Quick Map

| Action | Meta Quest 3 Controller Input |
| :--- | :--- |
| **Walk / Strafe (360° + Collision + Vignette)** | **Left Thumbstick** (Push in any direction) |
| **Teleport** | **Right Thumbstick** (Push **Forward** to aim blue arc, **Release** to teleport; hold **Right Grip** to cancel) |
| **Snap Turn (45°) / Smooth Turn** | **Right Thumbstick** (Flick **Left / Right**; toggle Smooth Turn in Tablet Settings) |
| **Grab / Hold / Drop Objects & Tablet** | **Left or Right Grip** (Hold to grab near hand or via far ray, release to drop/socket) |
| **Spin & Pull Closer/Farther (Held Object)** | **Thumbstick on Holding Hand** while gripping via Far Ray (**Left/Right** = Spin `180°/s`, **Up/Down** = Pull/Push `1.5 m/s`) |
| **Click UI, Push Buttons, Drag Sliders, Poke** | **Left or Right Trigger** (`UI Press` / `Activate`) or direct **Index Finger Poke** |
| **Summon / Dismiss Floating Lab Tablet** | **Left Controller `Y`** (`SecondaryButton`) |
| **Open Menu (Resume / Restart / Volume / Exit)** | **Left Controller `X`** (`PrimaryButton`) or **Menu** tab on Tablet *(Desktop: `Esc`)* |

## 2. Pinch & Hand Simulation Notes
* Installed XRI **`3.7.0`** includes full **Hand Expression simulation** (`Pinch Expression Capture.asset`, `Poke Expression Capture.asset`, `Grab Expression Capture.asset` via `XR Interaction Hand Controls.inputactions`).
* Pinch (`M`) and direct poke (`N` / `XRPokeFilter`) map cleanly to XRI **Select** so both controller trigger (`T`) and hand pinch/poke operate buttons, sockets, NPC speech controls, Lab Tablet, and Debug Panel without special-case code.
